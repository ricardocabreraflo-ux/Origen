Registrar cita directa

Para anotar una cita que ya se hizo (aunque no se haya agendado en el sistema) o llevar el control con fecha, hora, monto y duración libres. No se le manda ningún WhatsApp a la clienta.

Ambos vienen prellenados según el servicio — cámbialos si hubo descuento o si duró distinto (útil para el Servicio Especial).

Bloqueos de horario

Cierra un día completo o solo una parte (ej. "cerrado de 2 a 4pm") para que no se puedan agendar citas ahí. Los días bloqueados se muestran resaltados y también se sincronizan con Google Calendar.
